# 记忆流程简述

VocabProfiler 把“先收集词汇”和“今天开始背诵”分开。便签是独立的暂存区：可以随时记录、修改词汇，但不会进入学习或复习队列。需要开始学习时，在便签管理界面选择 **Apply to Notebook**，把词汇复制到指定笔记本；目标笔记本中已有的相同词面、释义和类型会被跳过。便签本身仍保留。

笔记本中的词汇按记忆目标分为两类：

- **Passive**：看到词汇时能认出释义，按正向卡片学习。
- **Active**：除了正向理解，还练习由释义回想词汇。系统会把正反向卡片分开放入队列；多义词可以在同一张卡片中逐项处理。

每类词汇都有 **New**（首次学习）和 **Review**（到期复习）入口。新词从等级 0 开始，学习时进入默认容纳五个词的记忆窗口；需要再练的词会回到队列。复习时可选择 **Mastered**、**Unclear** 或 **Forgotten**：掌握会推进等级，模糊或遗忘会降低进度并让词汇在本轮再次出现。Active 词汇的正反向结果会合并考虑，避免只记住一个方向就升级。

等级 1 至 6 对应的下次复习间隔依次为 **1、3、7、14、30、60 天**。
